# Plan 7.1: Services & Medicines VAT Configuration & POS Integration

## Objective
Implement master VAT configuration enabling administrators to set VAT (12% vs Exempt) globally across all services and all medicines or per item, and integrate dynamic VAT calculations in POS Billing.

## Context
- .gsd/SPEC.md
- .gsd/ROADMAP.md
- .gsd/phases/7/RESEARCH.md
- src/main/index.ts
- src/preload/index.ts
- src/renderer/src/components/ServicesManagerView.tsx
- src/renderer/src/components/POSBillingView.tsx

## Tasks

<task type="auto">
  <name>Implement backend services for bulk and per-item VAT configuration</name>
  <files>src/main/index.ts, src/preload/index.ts</files>
  <action>
    In `src/main/index.ts`:
    - Add handlers `services:set-all-vat(isVatable: boolean)`:
      - Updates or configures all services VAT flag in master settings / service records.
    - Add handlers `medicines:set-all-vat(isVatable: boolean)`:
      - Sets global default VAT flag for inventory medicine items in `SystemSetting` or inventory items.
    - Add handler `services:update-vat(id: number, isVatable: boolean)`:
      - Updates specific service item's VAT status.
    - Expose all three methods in `src/preload/index.ts`.
  </action>
  <verify>npm run build</verify>
  <done>IPC channels for service and medicine VAT configuration exposed and functional.</done>
</task>

<task type="auto">
  <name>Update ServicesManagerView and POSBillingView with dynamic VAT controls</name>
  <files>src/renderer/src/components/ServicesManagerView.tsx, src/renderer/src/components/POSBillingView.tsx</files>
  <action>
    In `src/renderer/src/components/ServicesManagerView.tsx`:
    - Add a "Set VAT on All Services" dropdown/button ("Set All 12% VAT" / "Set All VAT-Exempt") with confirmation modal.
    - Add a VAT badge / toggle switch per service item row in the table (showing "12% VAT" or "Exempt").
    
    In `src/renderer/src/components/POSBillingView.tsx`:
    - When loading service items and medicines into billing line items, resolve their `isVatable` status from the master service/inventory data or global setting.
    - Dynamically calculate 12% Output VAT on vatable lines, while keeping consultations and exempt items under VAT-exempt sales.
    - Ensure totals breakdown (Vatable Sales, VAT-Exempt Sales, 12% Output VAT, Total) recalculates in real-time.
  </action>
  <verify>npm run build</verify>
  <done>ServicesManagerView supports bulk and per-item VAT toggling; POSBilling accurately computes VAT based on item settings.</done>
</task>

## Success Criteria
- [ ] Users can bulk-set VAT on all services or all medicines with 1 click.
- [ ] Individual services can be toggled between VAT and Exempt.
- [ ] POS Billing reflects the configured VAT status and computes output tax accurately.
- [ ] `npm run build` exits 0.
