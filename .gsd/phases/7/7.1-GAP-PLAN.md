# Plan 7.1: Implement Medicines VAT Configuration UI and Logic

## Objective
The Phase 7 requirements demand "Configurable VAT on all services & medicines". While services have VAT configuration implemented via `ServicesManagerView` and `setAllServicesVat`, medicines completely lack any UI to set them as vatable globally or per item. This plan implements the required VAT configuration for medicines in `InventoryView` and the main process to satisfy the objective.

## Context
Load these files for context:
- .gsd/SPEC.md
- src/renderer/src/components/InventoryView.tsx
- src/preload/index.ts
- src/main/index.ts
