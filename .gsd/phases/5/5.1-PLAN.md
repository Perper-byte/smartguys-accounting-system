# Plan 5.1: Cash Disbursements Journal Running Totals & Check Disbursement Report Engine

## Objective
Implement cumulative running total computation for the Cash Disbursements Journal (CDJ) and build a dedicated Check Disbursement Report backend service compliant with BIR CAS (Computerized Accounting System) standards.

## Context
- .gsd/SPEC.md
- .gsd/ROADMAP.md
- .gsd/phases/5/RESEARCH.md
- src/main/services/reports.service.ts
- src/main/services/reports.service.test.ts

## Tasks

<task type="auto">
  <name>Add running totals to CDJ and implement Check Disbursement Report query</name>
  <files>src/main/services/reports.service.ts, src/preload/index.ts, src/main/index.ts</files>
  <action>
    In `ReportsService.getBooksOfAccounts`:
    - For `bookType === 'CDJ'` (and generic books where appropriate), calculate a continuous cumulative running total of disbursements across lines/entries:
      `runningBalance += line.credit` (for cash/bank reductions) or cumulative disbursement amount per entry.
    - Attach `runningTotal: number` to each formatted data item.
    
    Implement new method `ReportsService.getCheckDisbursementReport(startDateStr: string, endDateStr: string)`:
    - Query journal entries in the date range where `reference_no` starts with `CV-` or description/attachments indicate a check voucher.
    - Resolve check details: Date, Check/Voucher Reference (`entry.reference_no`), Payee (`entry.payee?.name`), Payee TIN (`entry.payee?.tin`), Description, Bank Account (`account 1020` or bank ledger), Gross Amount (sum of debits), Withholding Tax (Account `2050` credit), and Net Check Amount (`Account 1020` credit).
    - Compute cumulative running total of net check amounts.
    - Expose IPC channel `reports:get-check-disbursements` in main and preload.
    - Avoid skipping entries with multiple debit lines; aggregate them clearly per voucher.
  </action>
  <verify>npx jest src/main/services/reports.service.test.ts</verify>
  <done>ReportsService computes running totals for CDJ and returns structured check disbursement records with net check amounts and running totals.</done>
</task>
