# Plan 6.2: Books Closing Engine & Automated Closing Entries

## Objective
Implement the automated period-end / year-end books closing engine that generates balanced Closing Journal Entries zeroing out temporary accounts (Revenues and Expenses) to Retained Earnings (Account 3020), marks the period as `CLOSED`, and provides secure re-opening functionality.

<task type="auto">
  <name>Implement automated closing entries generator and reopen period functionality</name>
  <files>src/main/services/accounting-period.service.ts, src/preload/index.ts, src/main/index.ts</files>
  <action>
    In `src/main/services/accounting-period.service.ts`:
    - Implement `closePeriod(year: number, periodNumber: number, userId: string)`:
      - Validates that period is currently `OPEN` or `LOCKED`.
      - Queries all active journal lines within the period date range for:
        - Revenue accounts (type 'Revenue' / codes `4xxx`): sum of credits - debits.
        - Expense accounts (type 'Expense' / codes `5xxx`): sum of debits - credits.
      - Calculates Net Income = Total Revenues - Total Expenses.
      - Builds balanced closing journal entry lines:
        - For each revenue account with balance > 0: Debit line = balance, Credit line = 0.
        - For each expense account with balance > 0: Debit line = 0, Credit line = balance.
        - Retained Earnings / Equity (`3020` or `3010`):
          - If Net Income > 0 (Profit): Credit line = Net Income.
          - If Net Income < 0 (Loss): Debit line = Math.abs(Net Income).
      - Verifies strict mathematical balance: `totalDebits === totalCredits`.
      - Posts JournalEntry with `reference_no: CLOSE-${year}-P${periodNumber}`, `description: Period-End Closing Entry for Period ${periodNumber} (${year})`.
      - Updates period status to `CLOSED`, stores `closing_entry_id`, `closed_at: new Date()`, `closed_by: userId`.
    - Implement `reopenPeriod(year: number, periodNumber: number, userId: string, managerPin: string)`:
      - Validates Manager Override PIN using `LedgerService.verifyManagerPin`.
      - If valid, voids/deletes the closing journal entry and reverts period status to `OPEN`.
      - Logs audit event: `REOPEN_PERIOD`.
    - Expose IPC channels `calendar:close-period`, `calendar:reopen-period` in `main/index.ts` and `preload/index.ts`.
  </action>
  <verify>npm run build</verify>
  <done>closePeriod creates balanced closing entries zeroing out temporary accounts to Retained Earnings and locks the period.</done>
